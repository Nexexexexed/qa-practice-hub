# QA Practice Hub

Образовательная платформа для отработки навыков QA-инжиниринга в области автоматизированного UI-тестирования.

## Стек
- **Backend**: Node.js, Express, TypeScript, MongoDB, Redis, BullMQ
- **Раннер**: Docker, jsdom, mocha, chai
- **Документация**: Swagger (OpenAPI 3.0)

## Быстрый старт
1. `cd server && npm install && npm run dev`
2. MongoDB на `localhost:27017`
3. Redis на `localhost:6379`
4. Swagger: http://localhost:3000/api-docs
